API for agents

Discovery documents, a small MCP server, and optional OAuth metadata so agents can find Snaptapp without scraping HTML.

Public by default. Health, the API catalog, OpenAPI, and MCP tools on this origin do not require a token. Agent registration is documented in auth.md for agents that want a catalog-scoped Bearer token anyway.

API catalog

RFC 9727 catalog at /.well-known/api-catalog (application/linkset+json). OpenAPI is at /openapi.json. Health is GET /api/health.

MCP

Server card: /.well-known/mcp/server-card.json. Streamable HTTP endpoint: POST https://snaptapp.us/mcp.

Tools: get_studio_overview, list_products, get_contact_channels, get_discovery_documents.

OAuth and auth.md

  • OpenID Provider configuration
  • OAuth authorization server metadata (includes agent_auth)
  • Protected resource metadata
  • auth.md

Skills and ARD

  • Skills index: /.well-known/agent-skills/index.json
  • ARD catalog: /.well-known/ai-catalog.json

WebMCP

HTML pages call navigator.modelContext.provideContext() (and registerTool when that is what the browser exposes) so in-page agents can read studio facts and navigate the site.

More or Less

The trivia game is a different origin: moreorless.snaptapp.us. Player APIs authenticate with Firebase ID tokens, not the catalog OAuth on this host.
